## Descripción del proyecto

Este proyecto corresponde al desarrollo de un taller de **recursividad en Java**.

El objetivo principal es aplicar el concepto de recursividad mediante diferentes ejercicios en los cuales una función se llama a sí misma para resolver un problema.

Los ejercicios permiten practicar operaciones matemáticas, manejo de cadenas, arreglos, matrices y algoritmos recursivos.

## Ejercicios realizados

El proyecto contiene los siguientes ejercicios:

1. Cálculo del factorial de un número.
2. Inversión de un número entero.
3. Cálculo de la sumatoria de fracciones.
4. Suma de los dígitos de un número.
5. Cálculo de una sumatoria.
6. Cálculo de una potencia.
7. Cálculo del Máximo Común Divisor (MCD) mediante el algoritmo de Euclides.
8. Copia recursiva de una cadena.
9. Cálculo del cociente mediante restas sucesivas.
10. Multiplicación mediante sumas sucesivas.
11. Suma recursiva de los elementos de un arreglo.
12. Suma recursiva de los elementos de una matriz.
13. Serie de Fibonacci.
14. Función de Ackermann.

## Requisitos

Para ejecutar este proyecto se necesita:

- Tener instalado **Java JDK 17 o superior**.
- Tener instalado **Visual Studio Code**.
- Tener instalada la extensión **Extension Pack for Java** en Visual Studio Code.
- Tener instalado **Git** para trabajar con el repositorio.
